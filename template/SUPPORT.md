# Support

## Where to get help

- **Documentation**: `docs/` and this repository's README.
- **Bugs**: open an issue with the **Bug report** form.
- **Features**: open an issue with the **Feature request** form. Major
  design decisions require an ADR before implementation.
- **Security**: do NOT open an issue. See [SECURITY.md](SECURITY.md).

## Expectations

This is an open-source project maintained on a best-effort basis.
There is no SLA. Clear reproduction steps and scoped requests get the
fastest responses.

## Never include

Tokens, credentials, or private repository data in any issue, log, or
screenshot.
