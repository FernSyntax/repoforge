# Security Policy

## Supported versions

This project is pre-1.0. Only the latest release receives security
fixes.

## Reporting a vulnerability

**Report vulnerabilities privately. Never open a public issue.**

Use GitHub's private vulnerability reporting: this repository's
**Security tab → Report a vulnerability**. This creates a private
advisory visible only to the maintainers and you.

Please include:

- A description of the vulnerability and its impact.
- Steps to reproduce or a proof of concept.
- Affected versions, if known.

## What to expect

- Acknowledgment as promptly as the maintainers can manage; this
  project has no SLA.
- Coordinated disclosure: we investigate, fix privately, and agree on
  a public disclosure date with you.
- Credit in the release notes unless you prefer anonymity.

## Never include

Tokens, credentials, or private data in any report, issue, log, or
screenshot. If a token may be exposed, revoke it first, then report.
