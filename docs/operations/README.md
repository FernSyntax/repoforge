# Operations

Runbooks for operating RepoForge: publishing the template, maintaining
the wiki, recovering from failure, and rotating credentials. Procedures
here are executed step by step by maintainers, with verification at each
stage.

Policy lives in [development/release-process.md](../development/release-process.md);
these documents describe how to carry it out and what to do when it goes
wrong.

## Contents

- [template-publication.md](template-publication.md) — publishing the
  generated template, the GitHub App, and its credentials.
- [wiki-maintenance.md](wiki-maintenance.md) — seeding and synchronising
  the GitHub wiki.
- [first-day-runbook.md](first-day-runbook.md) — bringing a new
  repository under the standard, and recovering a drifted one.
- [incident-response.md](incident-response.md) — what to do when
  something has already gone wrong.
