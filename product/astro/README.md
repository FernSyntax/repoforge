## Develop

Requires Node.js 20 or later. Install once for reproducible builds:

```sh
npm ci
npm run check   # typecheck (.ts via strict tsc; see note below)
npm run build   # static output in dist/
npm run preview # serve dist/ locally
```

Type checking covers `.ts` sources through the strict tsconfig.
`.astro` frontmatter checking needs `@astrojs/check`, whose latest
release still peers on TypeScript 5/6 while this template pins
TypeScript 7 (latest): re-add it — and restore `astro check` as the
check script — once upstream supports TypeScript 7. Until then the
frontmatter stays deliberately simple and the Go-side build tests pin
the rendered contract.

## Search, answer, and generative engines

- Titles, descriptions, and Open Graph/Twitter tags derive from your project values.
- `WebSite` JSON-LD ships in the layout; `FAQPage` JSON-LD mirrors the visible FAQ exactly. Neither invents URLs: `url` fields stay out until the deployment hostname exists.
- `public/llms.txt` lists every page for answer engines; keep it in sync with `src/pages/`.
- Add `@astrojs/sitemap` once `site` is set in `astro.config.mjs`; the static `robots.txt` already allows crawling.

## Deploy

Ship the `dist/` directory to any static host. A `site` URL in
`astro.config.mjs` enables canonical URLs once the hostname is known.

Security headers depend on the host, so set them there rather than in
this template. A reasonable starting set for a static site:

- `Content-Security-Policy: default-src 'self'`
- `Referrer-Policy: strict-origin-when-cross-origin`
- `X-Content-Type-Options: nosniff`
- `Permissions-Policy: interest-cohort=()`

Verify each directive against what the deployment actually serves
(embedded media, fonts, and form endpoints change the answer); a
generic set is never universally safe.

- CMS or content collections: add when content outgrows pages.
- PWA/service worker: add only with an update and caching strategy.
- Analytics: add only with explicit consent handling and a privacy
  note; never by default.
- Sitemap integration: add `@astrojs/sitemap` once `site` is set.

## Privacy

ship by default. Keep it that way unless a feature earns its weight —
and document every exception here when you add one.
